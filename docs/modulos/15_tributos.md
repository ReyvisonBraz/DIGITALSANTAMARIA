# Tributos — `/tributos`

Informacoes sobre tributos e financas municipais.

**Dados:** Firestore real (`tax_records`)
**Padrao:** Catalogo (usa `useContent<TaxRecord>`)

## Dados exibidos

- Tipo de tributo (IPTU, ISS, ITBI, taxas)
- Valor, vencimento
- Status

## Admin

`GenericCatalogAdmin` para `tax_records`.
