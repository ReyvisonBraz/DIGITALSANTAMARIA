# Social — `/social`

Programas e servicos sociais do municipio.

**Dados:** Firestore real (`social_programs`)
**Padrao:** Catalogo (usa `useContent<SocialProgram>`)

## Dados exibidos

- Nome, categoria, descricao
- Requisitos para participacao
- Localizacao

## Admin

`GenericCatalogAdmin` para `social_programs`.
