# Servicos Publicos — `/servicos`

Diretorio de servicos publicos municipais.

**Dados:** Firestore real (`public_services`)
**Padrao:** Catalogo (usa `useContent<PublicService>`)

## Funcionalidades

- Grade de categorias de servico
- Busca client-side
- Cada servico: nome, categoria, departamento, localizacao, horario

## Admin

`GenericCatalogAdmin` para `public_services`.
