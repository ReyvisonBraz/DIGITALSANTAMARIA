# Comunidade — `/comunidade`

Grupos e iniciativas comunitarias.

**Dados:** Firestore real (`community_groups`)
**Padrao:** Catalogo (usa `useContent<CommunityGroup>`)

## Dados exibidos

- Nome, categoria, descricao
- Numero de membros
- Localizacao

## Admin

`GenericCatalogAdmin` para `community_groups`.
