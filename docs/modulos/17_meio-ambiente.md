# Meio Ambiente — `/meio-ambiente`

Dados e alertas ambientais do municipio.

**Dados:** Firestore real (`environment_data`)
**Padrao:** Catalogo (usa `useContent<EnvironmentData>`)

## Dados exibidos

- Tipo: qualidade do ar, agua, area verde, alerta
- Valor, unidade
- Localizacao

## Admin

`GenericCatalogAdmin` para `environment_data`.
