# Análise de Design: Saúde Fácil

## Visão Geral
Foca na utilidade prática e redução de atrito no acesso à saúde pública.

## Aplicação do DESIGN.md
- **Listagem de Unidades:** Cards com informações densas mas organizadas.
- **Indicadores de Espera:** Uso de contrastes tonais (Verde para baixa espera, Vermelho para alta) para informar rapidamente o cidadão.
- **Ações:** Botão de "Agendar Consulta" em destaque `primary-container`.

## Elementos Chave para Adaptação
1. **Modal de Agendamento:** Fluxo de seleção de data e horário seguindo o padrão de design mobile (bottom sheet).
2. **Dados Dinâmicos:** Estrutura pronta para receber dados de tempo de espera em tempo real.
3. **Geolocalização:** Ordenação de unidades por distância.
